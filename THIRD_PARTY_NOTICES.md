# Third-party notices and release status

NYC TLC trip data are reused from the NYC TLC public trip-record source.
No new licence is assigned to those data by this archive. Users should consult
the source's applicable terms before redistribution. Python dependencies retain
their respective licences and are installed separately, not bundled here.

The authors have requested preparation for open-source release but have not
specified a code licence or copyright-holder string. This review archive therefore
does not invent one; the authors must add their chosen LICENSE before publishing
it as an open-source release. This does not prevent reviewers from inspecting
the locally supplied code and reproduction artifacts.

GAN checkpoint files use Python/PyTorch pickle serialization and refer to the
included code modules. Load checkpoints only from a trusted copy of this archive.
